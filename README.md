SALES & PRODUCT ANALYSIS

Project Overview:
 This project analyzes sales transactions to identify product revenue, category performance, regional sales and monthly revenue trends.

Tools Used:
- Microsoft SQL Server
- SQL
- Google Sheets
- Pivot Tables, XLOOKUP and Charts

Dataset:
 The project uses sample data containing 10 products and 20 sales transactions from January to March 2026.

Key Analysis:
- Total revenue and quantity sold
- Revenue by product
- Revenue by product category
- Revenue by region
- Monthly revenue trends
- Top 5 products by revenue

Dashboard:
 Created a dashboard with KPI summaries and charts to present the analysis visually.

SQL Concepts:
- SELECT, WHERE and ORDER BY
- Aggregate functions
- GROUP BY and HAVING
- INNER JOIN
- Calculated fields

Project Files:
- `sales_analysis.sql` — SQL script and analysis queries
- `Sales_Analysis.xlsx` — Data analysis and dashboard

Note:
 This project uses sample data for learning and portfolio demonstration.
